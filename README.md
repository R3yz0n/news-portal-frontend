# News Portal Frontend

This is the frontend client for the News Portal project, built with React and Tailwind CSS.

## Features

- Responsive UI for news, categories, user login, dashboard, and more
- CKEditor integration for rich text editing
- Modular components and pages
- API integration with backend server

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
   The app will run at [http://localhost:3000](http://localhost:3000).

## Folder Structure

- `src/` - Main source code
- `public/` - Static assets
- `ckeditor5/` - Custom CKEditor build

## Build

To build for production:

```bash
npm run build
```

Output will be in the `build/` folder.
